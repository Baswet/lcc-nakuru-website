# Deliverance Church International – Life Celebration Centre (LCC), Nakuru

Website for LCC Nakuru: **preview build**. All content comes from public, verifiable sources. Items still to be confirmed with the church office are clearly labelled or withheld.

**Live preview:** https://baswet.github.io/lcc-nakuru-website/

## Structure
| Path | What |
|---|---|
| `*.html` | Pages generated by `tools/build.py` from `data/content.json` |
| `data/content.json` | Single source of truth: services, giving, videos, events, news, notice |
| `assets/` | CSS, JS, self-hosted fonts (SIL OFL), images |
| `api/` | Form endpoints (PHP hosting only) |
| `admin/` | Simple CMS (PHP hosting only) |
| `private/` | Server-only helpers and submissions; web access denied |
| `docs/` | Research, competitor analysis, design system, testing report, screenshots |

## Edit content
1. **Static (GitHub Pages):** edit `data/content.json`, run `python3 tools/build.py`, then commit.
2. **PHP host (7.4–8.4):** upload everything, run `php tools/set-admin-password.php <username>` on the server, then sign in at `/admin/`. Admin changes show immediately in the dynamic sections (notice, giving, sermon library). Run the build to refresh the pre-rendered HTML for search engines.

## Before launch (church office to confirm)
- [ ] Sunday service times
- [ ] Official giving details (M-Pesa paybill and account). **Do not publish unconfirmed numbers.**
- [ ] Church history and pastoral team
- [ ] Approved photographs and official logo
- [ ] Ministry details and contacts
- [ ] Domain name (update `site.url` in content.json, then rebuild)

## Security notes
Passwords are hashed with Argon2id or bcrypt. CSRF protection, rate limiting, a honeypot, session hardening, re-encoded uploads and backups before every save are built in. Never commit `private/config.php`.
