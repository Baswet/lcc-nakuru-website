# Typography

Fonts are self-hosted from `assets/fonts` (no Google Fonts call, which helps privacy and speed). Licence: SIL OFL (via @fontsource).

- **Display: Fraunces** (variable weight 300–700, italic). Headlines use weight 350–420 with tight tracking (-0.03em). Italic in clay marks the emphasised word.
- **Text and UI: Inter Tight** (variable 400–700). 17px body, line-height 1.6.

| Role | Size (fluid) | Weight / style |
|---|---|---|
| Display (hero) | clamp(44px, 7.2vw, 108px) / 0.98 | Fraunces 350 |
| H2 | clamp(32px, 4.2vw, 56px) / 1.05 | Fraunces 380 |
| H3 | 22–26px / 1.2 | Fraunces 500 |
| Eyebrow | 12px, +0.2em, uppercase | Inter Tight 600, clay |
| Body | 17px / 1.6 (18px on large screens) | Inter Tight 400 |
| Small / meta | 14px | Inter Tight 500, muted |

Measure is capped at about 68ch for prose. Swahili titles (e.g. "Sijaona kama wewe") are left in the original language.
